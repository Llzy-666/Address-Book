# 演示脚本（录屏用）

> 目标：录一条 **2–3 分钟**的完整运行视频。
> 前置：已经 `pip install -r requirements.txt`，并已执行 `python seed.py` 灌好演示数据。
> 建议分辨率 1440×900 或更高，浏览器缩放 100%，录制工具用 OBS 或 Windows 自带录屏（Win+G）。

---

## 一、录制前检查（不录进视频）

1. 关掉无关窗口，浏览器只留一个标签页。
2. 确认 `data/address_book.db` 存在且是种子数据（5 个联系人、2 个收藏）。
3. 打开终端，路径切换到项目根目录。
4. 准备好资源管理器窗口，停在项目根目录，方便演示导出的 xlsx。

---

## 二、分镜脚本

### 镜头 1 · 启动后端（约 15 秒）

| 操作 | 解说要点 |
| --- | --- |
| 终端执行 `python app.py` | 「Flask 监听 0.0.0.0:5000」 |
| 观察输出 `* Running on http://127.0.0.1:5000` | 强调没有报错、一次启动成功 |

### 镜头 2 · 打开列表页（约 10 秒）

| 操作 | 解说要点 |
| --- | --- |
| 浏览器访问 `http://127.0.0.1:5000/` | 卡片式布局、收藏项左侧有强调色条 |
| 鼠标划过卡片 | 悬停有轻微上浮与阴影过渡 |

**对应截图**：`01-list.png`

### 镜头 3 · 搜索（约 10 秒）

| 操作 | 解说要点 |
| --- | --- |
| 搜索框输入 `福州` | 输入防抖 300ms 自动筛选，只剩匹配的卡片 |
| 清空搜索框 | 列表恢复 |

### 镜头 4 · 新增一个含 3 种联系方式的联系人（约 40 秒）

| 操作 | 解说要点 |
| --- | --- |
| 点右上角「新增」 | 右侧抽屉滑出 |
| 姓名填 `演示同学`，公司填 `福州大学`，备注填 `录屏演示用` | 字段说明 |
| 第 1 行：类型选「电话」，值填 `13612345678` | |
| 点「+ 添加一条联系方式」 | 动态增行 |
| 第 2 行：类型选「邮箱」，备注填 `学校邮箱`，值填 `demo@fzu.edu.cn` | 演示 label 可自定义 |
| 再加一行：类型选「微信」，值填 `demo_wx` | 共 3 条、3 种类型 |
| 点「保存」 | 抽屉关闭，列表出现新卡片 |

**对应截图**：`02-create-drawer.png`（保存前，含 3 条联系方式）

### 镜头 5 · 收藏与筛选（约 25 秒）

| 操作 | 解说要点 |
| --- | --- |
| 点新卡片的星标 | 图标立即由空心变实心，卡片左侧出现强调色条，右上角 toast 提示「已加入收藏」 |
| 点「只看收藏」 | 只显示收藏的联系人 |
| **刷新页面（F5）** | 强调：刷新后收藏状态仍在，说明已落库而非前端临时态 |
| 点回「全部」 | 列表恢复 |

**对应截图**：`03-favorites.png`（只看收藏的列表页）

### 镜头 6 · 编辑与删除（约 25 秒）

| 操作 | 解说要点 |
| --- | --- |
| 某卡片点「编辑」 | 抽屉回填原有数据（含全部联系方式行） |
| 改备注为 `已编辑`，加一条「地址」，保存 | 列表即时更新 |
| 对演示同学点「删除」 | 弹出二次确认，显示联系人姓名 |
| 点「取消」再点「删除」并确认 | 强调有二次确认，防止误删 |

**对应截图**：`04-edit-drawer.png`（编辑态）

### 镜头 7 · 导出 Excel（约 20 秒）

| 操作 | 解说要点 |
| --- | --- |
| 点「导出」 | 浏览器下载 `contacts_YYYYMMDD.xlsx` |
| 用 Excel 打开该文件 | 一行一联系人；张三那行 3 条电话/邮箱分列；孙七有多条联系方式仍在同一行 |
| 指出 `是否收藏` 列是「是/否」，首行加粗且冻结 | 对照 Excel 规则逐条说明 |

**对应截图**：`05-excel-export.png`（Excel 打开的导出结果）

### 镜头 8 · 导入失败演示（约 25 秒）

| 操作 | 解说要点 |
| --- | --- |
| 打开导出的 xlsx，**删掉「邮箱2」整列**后另存 | 故意制造表头不符 |
| 回到页面点「导入」 | 弹窗说明三步流程 |
| 选这个被改过的文件，点「开始导入」 | 面板标红：「导入失败 · 表头不符合模板，请下载模板后填写」 |

**对应截图**：`06-import-error.png`

### 镜头 9 · 导入成功演示（约 25 秒）

| 操作 | 解说要点 |
| --- | --- |
| 点「下载模板」 | 得到空白模板 |
| 按模板填 2–3 行（其中一行**姓名留空**） | 说明姓名为空会被跳过 |
| 选这个文件导入 | 面板转黄：「成功新增 2 条，跳过 1 条」，并列出「第3行：姓名不能为空」 |

**对应截图**：`07-import-success.png`

### 镜头 10 · 响应式（约 15 秒）

| 操作 | 解说要点 |
| --- | --- |
| F12 打开开发者工具，切设备模拟 | |
| 宽度拖到 900px 左右 | 三列变两列 |
| 拖到 600px 以下 | 单列；打开抽屉时铺满全屏 |

### 镜头 11 · 收尾（约 10 秒）

| 操作 | 解说要点 |
| --- | --- |
| 回到终端，`Ctrl+C` 停止服务 | 「本地部署完成，导入导出往返一致」 |
